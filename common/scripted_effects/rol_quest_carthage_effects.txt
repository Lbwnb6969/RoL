# Mythic Relics - 突尼斯浴火金面任务链推进逻辑（已重构收敛至公共模板）
# 变量：rol_carthage_stage_count（角色作用域）

rol_carthage_quest_progress_effect = {
	if = {
		limit = { rol_carthage_quest_active_trigger = yes }
		if = {
			limit = { NOT = { has_variable = rol_carthage_stage_count } }
			set_variable = { name = rol_carthage_stage_count value = 0 }
		}
		change_variable = { name = rol_carthage_stage_count add = 1 }
		rol_relic_log_stage_effect = yes
		rol_relic_debug_trace_effect = { DEBUG_KEY = rol_relic_debug_carthage_stage_progress }
		rol_relic_try_guest_or_rival_interlude_effect = {
			STAGE_VAR = rol_carthage_stage_count
			MAX_STAGE = 2
			GUEST_FLAG = rol_carthage_guest_event_fired
			RIVAL_FLAG = rol_rival_route_carthage
			FALLBACK_EVENT = rol_quest_carthage.1050
		}
		if = {
			limit = { var:rol_carthage_stage_count < 2 }
			trigger_event = { id = rol_quest_carthage.1002 days = 14 }
		}
		else = {
			trigger_event = { id = rol_quest_carthage.1001 days = 10 }
		}
	}
}

rol_carthage_clamp_success_progress_effect = {
	rol_relic_clamp_activity_progress_effect = yes
}

rol_carthage_apply_tiered_bonus_reward_effect = {
	if = {
		limit = { exists = scope:activity scope:activity.var:activity_special_type_progression >= 55 }
		add_prestige = 320
		add_piety = 140
	}
	else_if = {
		limit = { exists = scope:activity scope:activity.var:activity_special_type_progression >= 45 }
		add_prestige = 200
		add_piety = 90
	}
	else_if = {
		limit = { exists = scope:activity scope:activity.var:activity_special_type_progression >= 35 }
		add_prestige = 110
		add_piety = 50
	}
	else = {
		add_prestige = 60
	}
}

rol_carthage_store_success_result_effect = {
	rol_relic_store_tiered_success_result_effect = {
		TIER4 = 55
		TIER3 = 45
		TIER2 = 35
		SUCCESS_FLAG = rol_recent_carthage_quest_success
		FAILURE_FLAG = rol_recent_carthage_quest_failure
	}
}

rol_carthage_store_failure_result_effect = {
	rol_relic_store_failure_result_common_effect = {
		SUCCESS_FLAG = rol_recent_carthage_quest_success
		FAILURE_FLAG = rol_recent_carthage_quest_failure
	}
}

rol_carthage_quest_success_finalize_effect = {
	if = {
		limit = { rol_carthage_quest_active_trigger = yes }
		rol_expedition_companion_finish_effect = { STAGE_VARIABLE = rol_carthage_stage_count }
		rol_expedition_growth_finish_effect = { ROUTE = carthage RESULT_XP = 30 LEAVE_NOTES = no }
		rol_carthage_clamp_success_progress_effect = yes
		rol_carthage_store_success_result_effect = yes
		rol_carthage_apply_tiered_bonus_reward_effect = yes
		add_character_flag = rol_ash_forged_mask_claimed
		rol_relic_complete_success_tail_effect = {
			HEARD_FLAG = rol_heard_carthage_legend
			COOLDOWN_MODIFIER = rol_carthage_quest_cooldown_modifier
			TOAST_TITLE = rol_carthage_activity_success_toast_title
			TOAST_DESC = rol_carthage_activity_success_toast_desc
			SUMMARY_EVENT = rol_quest_carthage.1090
			CLEAR_CONTEXT_EFFECT = rol_clear_context_carthage_helmet_effect
			ABORT_EFFECT = rol_carthage_quest_abort_effect
			DEBUG_KEY = rol_relic_debug_carthage_success_finalize
		}
	}
}

rol_carthage_quest_partial_finalize_effect = {
	if = {
		limit = { rol_carthage_quest_active_trigger = yes }
		rol_expedition_companion_finish_effect = { STAGE_VARIABLE = rol_carthage_stage_count }
		rol_expedition_growth_finish_effect = { ROUTE = carthage RESULT_XP = 20 LEAVE_NOTES = yes }
		rol_relic_cap_partial_progress_effect = { MAX = 54 }
		rol_carthage_clamp_success_progress_effect = yes
		rol_carthage_store_success_result_effect = yes
		rol_carthage_apply_tiered_bonus_reward_effect = yes
		rol_store_recent_expedition_preparation_effect = yes
		rol_relic_partial_success_finalize_effect = {
			PARTIAL_MODIFIER = rol_partial_relic_evidence_modifier
			COOLDOWN_MODIFIER = rol_carthage_quest_cooldown_modifier
			SUMMARY_EVENT = rol_quest_carthage.1090
			DEBUG_KEY = rol_relic_debug_carthage_partial_finalize
		}
		rol_clear_context_carthage_helmet_effect = yes
		rol_carthage_quest_abort_effect = yes
		rol_relic_quest_close_effect = yes
	}
}

rol_apply_carthage_activity_cooldown_effect = {
	if = {
		limit = { rol_carthage_quest_active_trigger = yes }
		if = {
			limit = { has_variable = rol_carthage_stage_count var:rol_carthage_stage_count >= 1 }
			rol_expedition_growth_finish_effect = { ROUTE = carthage RESULT_XP = 10 LEAVE_NOTES = no }
		}
		else = { rol_expedition_growth_abandon_effect = yes }
		rol_expedition_companion_finish_effect = { STAGE_VARIABLE = rol_carthage_stage_count }
		rol_relic_failure_finalize_tail_effect = {
			COOLDOWN_MODIFIER = rol_carthage_quest_cooldown_modifier
			STORE_FAILURE_EFFECT = rol_carthage_store_failure_result_effect
			TOAST_TITLE = rol_carthage_activity_failure_toast_title
			TOAST_DESC = rol_carthage_activity_failure_toast_desc
			SUMMARY_EVENT = rol_quest_carthage.1090
			CLEAR_CONTEXT_EFFECT = rol_clear_context_carthage_helmet_effect
			DEBUG_KEY = rol_relic_debug_carthage_failure_finalize
		}
	}
}

rol_carthage_quest_fail_now_effect = {
	if = {
		limit = { rol_carthage_quest_active_trigger = yes }
		rol_apply_carthage_activity_cooldown_effect = yes
		rol_carthage_quest_abort_effect = yes
		rol_relic_debug_trace_effect = { DEBUG_KEY = rol_relic_debug_carthage_fail_now }
	}
}

rol_carthage_quest_abort_effect = {
	if = {
		limit = { has_variable = rol_carthage_stage_count }
		remove_variable = rol_carthage_stage_count
	}
}
