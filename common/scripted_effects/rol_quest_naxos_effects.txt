# Mythic Relics - 纳克索斯活动推进逻辑（已重构收敛至公共模板）
# 变量：rol_naxos_stage_count（角色作用域）

rol_naxos_quest_progress_effect = {
	if = {
		limit = { rol_naxos_quest_active_trigger = yes }
		if = {
			limit = { NOT = { has_variable = rol_naxos_stage_count } }
			set_variable = { name = rol_naxos_stage_count value = 0 }
		}
		change_variable = { name = rol_naxos_stage_count add = 1 }
		rol_relic_log_stage_effect = yes
		rol_relic_debug_trace_effect = { DEBUG_KEY = rol_relic_debug_naxos_stage_progress }
		rol_relic_try_guest_or_rival_interlude_effect = {
			STAGE_VAR = rol_naxos_stage_count
			MAX_STAGE = 3
			GUEST_FLAG = rol_naxos_guest_event_fired
			RIVAL_FLAG = rol_rival_route_naxos
			FALLBACK_EVENT = rol_quest_naxos.1050
		}
		if = {
			limit = { var:rol_naxos_stage_count = 1 }
			trigger_event = { id = rol_quest_naxos.1002 days = 12 }
		}
		else_if = {
			limit = { var:rol_naxos_stage_count = 2 }
			trigger_event = { id = rol_quest_naxos.1003 days = 16 }
		}
		else = {
			trigger_event = { id = rol_quest_naxos.1001 days = 8 }
		}
	}
}

rol_naxos_clamp_success_progress_effect = {
	rol_relic_clamp_activity_progress_effect = yes
}

rol_naxos_apply_tiered_bonus_reward_effect = {
	if = {
		limit = { exists = scope:activity scope:activity.var:activity_special_type_progression >= 60 }
		add_prestige = 220
		add_gold = 80
	}
	else_if = {
		limit = { exists = scope:activity scope:activity.var:activity_special_type_progression >= 45 }
		add_prestige = 150
		add_gold = 50
	}
	else_if = {
		limit = { exists = scope:activity scope:activity.var:activity_special_type_progression >= 30 }
		add_prestige = 90
	}
	else = {
		add_prestige = 40
	}
}

rol_naxos_store_success_result_effect = {
	rol_relic_store_tiered_success_result_effect = {
		TIER4 = 60
		TIER3 = 45
		TIER2 = 30
		SUCCESS_FLAG = rol_recent_naxos_quest_success
		FAILURE_FLAG = rol_recent_naxos_quest_failure
	}
}

rol_naxos_store_failure_result_effect = {
	rol_relic_store_failure_result_common_effect = {
		SUCCESS_FLAG = rol_recent_naxos_quest_success
		FAILURE_FLAG = rol_recent_naxos_quest_failure
	}
}

rol_naxos_quest_success_finalize_effect = {
	if = {
		limit = { rol_naxos_quest_active_trigger = yes }
		rol_expedition_companion_finish_effect = { STAGE_VARIABLE = rol_naxos_stage_count }
		rol_expedition_growth_finish_effect = { ROUTE = naxos RESULT_XP = 30 LEAVE_NOTES = no }
		rol_naxos_clamp_success_progress_effect = yes
		rol_naxos_store_success_result_effect = yes
		rol_naxos_apply_tiered_bonus_reward_effect = yes
		add_character_flag = rol_naxos_unit_unlocked
		rol_check_legend_circle_revelation_effect = yes
		rol_relic_complete_success_tail_effect = {
			HEARD_FLAG = rol_heard_naxos_legend
			COOLDOWN_MODIFIER = rol_naxos_quest_cooldown_modifier
			TOAST_TITLE = rol_naxos_activity_success_toast_title
			TOAST_DESC = rol_naxos_activity_success_toast_desc
			SUMMARY_EVENT = rol_quest_naxos.1090
			CLEAR_CONTEXT_EFFECT = rol_clear_context_naxos_relic_effect
			ABORT_EFFECT = rol_naxos_quest_abort_effect
			DEBUG_KEY = rol_relic_debug_naxos_success_finalize
		}
	}
}

rol_naxos_quest_partial_finalize_effect = {
	if = {
		limit = { rol_naxos_quest_active_trigger = yes }
		rol_expedition_companion_finish_effect = { STAGE_VARIABLE = rol_naxos_stage_count }
		rol_expedition_growth_finish_effect = { ROUTE = naxos RESULT_XP = 20 LEAVE_NOTES = yes }
		rol_relic_cap_partial_progress_effect = { MAX = 59 }
		rol_naxos_clamp_success_progress_effect = yes
		rol_naxos_store_success_result_effect = yes
		rol_naxos_apply_tiered_bonus_reward_effect = yes
		rol_store_recent_expedition_preparation_effect = yes
		rol_relic_partial_success_finalize_effect = {
			PARTIAL_MODIFIER = rol_partial_relic_evidence_modifier
			COOLDOWN_MODIFIER = rol_naxos_quest_cooldown_modifier
			SUMMARY_EVENT = rol_quest_naxos.1090
			DEBUG_KEY = rol_relic_debug_naxos_partial_finalize
		}
		rol_clear_context_naxos_relic_effect = yes
		rol_naxos_quest_abort_effect = yes
		rol_relic_quest_close_effect = yes
	}
}

rol_apply_naxos_activity_cooldown_effect = {
	if = {
		limit = { rol_naxos_quest_active_trigger = yes }
		if = {
			limit = { has_variable = rol_naxos_stage_count var:rol_naxos_stage_count >= 1 }
			rol_expedition_growth_finish_effect = { ROUTE = naxos RESULT_XP = 10 LEAVE_NOTES = no }
		}
		else = { rol_expedition_growth_abandon_effect = yes }
		rol_expedition_companion_finish_effect = { STAGE_VARIABLE = rol_naxos_stage_count }
		rol_relic_failure_finalize_tail_effect = {
			COOLDOWN_MODIFIER = rol_naxos_quest_cooldown_modifier
			STORE_FAILURE_EFFECT = rol_naxos_store_failure_result_effect
			TOAST_TITLE = rol_naxos_activity_failure_toast_title
			TOAST_DESC = rol_naxos_activity_failure_toast_desc
			SUMMARY_EVENT = rol_quest_naxos.1090
			CLEAR_CONTEXT_EFFECT = rol_clear_context_naxos_relic_effect
			DEBUG_KEY = rol_relic_debug_naxos_failure_finalize
		}
	}
}

rol_naxos_quest_fail_now_effect = {
	if = {
		limit = { rol_naxos_quest_active_trigger = yes }
		rol_apply_naxos_activity_cooldown_effect = yes
		rol_naxos_quest_abort_effect = yes
		rol_relic_debug_trace_effect = { DEBUG_KEY = rol_relic_debug_naxos_fail_now }
	}
}

rol_naxos_quest_abort_effect = {
	if = {
		limit = { has_variable = rol_naxos_stage_count }
		remove_variable = rol_naxos_stage_count
	}
}
