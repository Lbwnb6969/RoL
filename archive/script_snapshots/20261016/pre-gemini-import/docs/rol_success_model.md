# RoL 成功率、成本与成长模型

2026-10-07 全面静态复核。下列数值来自当前活动、事件、修正源码，以及本机 CK3 1.20.0.3 的 `00_activity_effects.txt` / `00_maa_types.txt`。它们是路线算术与源码契约，尚未经过引擎实测。

## 真实主线与完整奖励门槛

原版推进量为 major +10、medium +5、tiny +3、negative −5、negative_major −10。终局检查进度；Tier4 给完整奖励，Tier2/3 给部分成果，检定失败分支通常直接收束。因此“检定成功”与“完整奖励”不是同一个条件。

| 地区 | 起点 / Tier4 | 主阶段事件 | 全部随机、高属性标准筹备 | 可选稳定开局后 |
|---|---|---|---:|---:|
| Rome | 30 / 70 | 1000、1002、1003、1004 | 90%⁴ = 65.61% | learning≥15 的 1000.b → 90%³ = 72.90% |
| Munich | 35 / 55 | 1000、1002 | 90%² = 81.00% | 护卫/专长首关 → 90% = 90.00% |
| Naxos | 30 / 60 | 1000、1002、1003 | 90%³ = 72.90% | learning≥13 的 1000.b → 90%² = 81.00% |
| Sevilla | 35 / 55 | 1000、1002 | 90%² = 81.00% | 护卫/专长/图表首关 → 90% = 90.00% |
| Carthage | 35 / 55 | 1000、1002 | 90%² = 81.00% | 护卫/专长首关 → 90% = 90.00% |

表格假设选择达到高属性档且成功给予 major 的路线，后续必要检定独立，且旅行、竞争者及宾客事件没有额外损失。它不代表一次完整游戏远征的实测通过率。Rome 可走稳定学习开局，随后选 1002.a、1003.a、1004.a；Naxos 可走稳定学习开局，随后选 1002.b、1003.a。其他三链可选各自主阶段的90%高档路线。

旧文档把 Naxos 写成四关、其余短链写成三关，导致虚报统一72.9%。当前纠正说明，保留既有90%高属性分支；“约70%”是早期设计目标，当前有利短路线高于此目标，不为追齐文档暗改玩法难度。Naxos 1003.b 的高谋略成功原为 medium、低档成功反而 major，本轮修成 major；其70%成功率保持原值，不是90%路线。

## 单次概率与选择收益

`实际成功率 = clamp(基准 + 筹备 + 地区笔记 + 在场学者, 5, 95)`。失败权重为100减成功率，tooltip读取同一算式。筹备 low −10、standard 0、high +10、supreme +20；同地笔记 +5，在场且存活的学者 +3。

| 剩余必要90%检定数 | 标准 | 学者93% | 高/极致或笔记95% |
|---:|---:|---:|---:|
| 1 | 90.00% | 93.00% | 95.00% |
| 2 | 81.00% | 86.49% | 90.25% |
| 3 | 72.90% | 80.44% | 85.74% |
| 4 | 65.61% | 74.81% | 81.45% |

笔记在下次同地区出发时一次消耗，其他地区不消耗；学者死亡/离队不再提供+3。二者合计仍受95%封顶。确定高档首关只减少一道随机检定，不绕过后续进度与唯一奖励条件。护卫75金币、专长60XP解锁的100金币路线、对应图表40金币路线共用一次限额；Rome/Naxos 原有免费学习路线对合格人物仍很有价值，付费路线主要服务其他属性构筑。

64个挑战列表、88个结果提示键由静态检查覆盖。真实tooltip、在场判定和引擎权重仍须手测。

## 成本与回报

| 活动 | low / standard / high / supreme 总金币 | Tier4 基础终局收益 |
|---|---|---|
| Rome | 180 / 300 / 750 / 1900 | 250威望、150虔诚、Mars剑 |
| Munich | 280 / 400 / 850 / 2000 | 200威望、300虔诚、星界球 |
| Naxos | 230 / 350 / 800 / 1950 | 220威望、80金币、招募资格 |
| Sevilla | 280 / 400 / 850 / 2000 | 350威望、150金币、星盘 |
| Carthage | 280 / 400 / 850 / 2000 | 320威望、140虔诚、金面 |

以上不含旅行费用、阶段收益、同行报酬、碎片、用途或圆环。完整成功的 high 另加150威望/25宗族威望，supreme另加350/50；部分成功不再获得完整凯旋筹备奖励。

在90%基准上 high 与 supreme 同为95%；多付1150金币只换额外200威望/25宗族威望。极致档在较低基准上仍能提高胜算，在高属性构筑上属于昂贵的凯旋选项。保留现有价目，记录其收益差异，等待手测决定是否有必要重新定价。

碎片每次正式决策120金币、两年冷却，第三种挑战成功另付50金币；每件上限两级，一级和二级累计。失败压力/冷却是代价，转手或目标失效不换物品领奖。用途每年最多立一项目，50金币、180天等待，第181天成果可选10XP或100威望；停止/失效不退款且不清冷却。

## 成长节奏与叠加上限

远征完整/部分/已有阶段的失败分别给30/20/10点复盘经验，无阶段失败不给。三轨各20/60/100分档并在100封顶。只投同一轨且无同行经验时，完整远征第1/2/4次跨过三个门槛；充分同行履约另给10，同轨可在第3次达到100。五链基础完整结算总计150XP，同行充分履约最高另50，仍须选择分配，不是每轨同时满级。

仅靠每年用途成果把一个空轨道推到100，需要10个成功项目、总500金币，项目开启跨度至少9年加最后半年等待。部分成功的十年地区笔记提供有限重试优势；失败/部分结算两年冷却，不能无成本立即循环刷经验。源码模型已检查重复兑现、取消和旧窗口，不模拟真实日历。

互斥组：三种研习、守信/失信声誉、三种传承取向、每件两种用途、Naxos两种训练。切换只清对应 RoL 修正。真品、传奇阶位、两级碎片、用途之间是刻意累计的不同来源。

四件真品若同时装备，基础月威望增益合计53%，各传奇阶位再加10%，合计93%；满碎片另7%，星界球展示用途另5%，圆环和临时角色奖励还会继续增加。这是明显的传奇成长强度，不能把互斥检查误写成“全部BUFF不叠加”。当前未无依据削弱既有终局装备；实际装备叠加、战斗与经济效果须由手测评估。

Naxos 每级兵团4人，单兵伤害960/坚韧720，对照原版重步兵100人×32/22，名义每级总量3840/2880对3200/2200，约1.20/1.31倍；补给成本12对7，招募使用 accolade 重步兵费用，维护使用普通重步兵费用。它没有原版重步兵的克制项，极小人数还会影响减员与战斗结算；不能直接把单兵30倍当成整团30倍，亦不能用总量算术宣称战斗已平衡。
