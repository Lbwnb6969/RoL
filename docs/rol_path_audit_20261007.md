## 值得增加的内容：按优先级

下面是设计建议，未擅自实施新故事、BUFF或削弱旧物品；先通过游戏验收，再做一小批。

1. **有限补救选择。** 已有地区笔记、60XP专长和实际同行，应允许其中一种帮助处理一次中途失败，给出付费继续到“部分成果”、救人后撤或立即撤退的选择。活动内最多一次；消费笔记/能力资格，收取明确费用；不恢复完整成功资格或再加一关随机检定。可用一个只记录“已用补救”的活动变量，不需要永久BUFF。
2. **同一同行/竞争者的后续。** 根据是否履约、上次探险贡献和原NPC身份给一次针对性的返场选择，例如请老搭档整理证据、偿清积怨或拒绝再合作。收益优先用原有好感、压力和限定路线。它补足关系记忆，比再随机抽一名人物、再给普遍好感更有价值。
3. **改造已有年度事件。** 将“持有圣物→威望/虔诚二选一”改成根据实际用途和人格出现的职责选择：公开展示与保密、研究与演练、资助与婉拒。优先消费既有状态/产生一次知识，而不是复制新的年度弹窗。仍按原物品、五年冷却与本次编号结算。
4. **更清楚的阶段与成果反馈。** 合并零选择的反馈事件后，把伤势、费用、阶段完成数、部分成果和下一步入口放入现有活动日志/结算。已有图片继续使用。让玩家知道为什么拿到部分成果，比增加被动BUFF更重要。

如确实需要新BUFF，优先局限在一次活动或三年内：针对一条路线的一次费用减免、原NPC好感或有来源的旅行安全。先指定生产/消费、对象、期限、互斥组、重开守卫和反馈，再定数值。当前没有依据新增永久军事、学习、领地上限或宗族倍率。
