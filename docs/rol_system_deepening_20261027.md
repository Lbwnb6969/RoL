# RoL 系统深化施工方案

更新：2026-10-27。新一轮目标来自维护者“了解项目、设计后持续施工”；取代旧计划中“静态收尾后不再拓展”的工作安排。游戏测试继续由维护者执行。

## 判断与取舍

RoL 的核心已经是完整的五条远征，而不是待补齐的原型。发现、活动、阶段选择、完整/部分/失败结算连接着三轨专长、地区笔记、同行契约、圣物用途、碎片、竞争者和继承。10月16日的交付还实现了危机补救、动态碎片概率、三取向共鸣、双圣物教义、老搭档重逢及年度用途联动。

目前的短板是长期状态缺少足够的行为消费者：竞争者合作/积怨没有绑定原人物；知识只能随人过期或死亡打包；100XP专长仍以属性档位为主。继续增加相似远征或永久倍率，会增加维护量而不改善这些问题。

本轮先补人物连续性与家族知识经营，同时修复碰到的任务身份缺口。保留既有五链、Tier4真品、Tier2/3部分成果、四/五圆环语义及全部可用美术。

## 第一批施工（已完成）

### A：碎片任务身份闭环

碎片升级共鸣已有编号，但挑战窗口仍读角色当前目标。补齐挑战任务的单调编号：启动时捕获原任务，挑战、取消和失效关闭只操作同一编号。成功/失败、转手后的无奖励收束及原费用、概率保持既有规则。

增加免费恢复入口，允许旧存档未编号的待处理任务获得编号后重开；旧窗口本身不猜测新任务身份。验收覆盖四种物品、同物品下一次任务、跨物品任务、重复点击、换主和旧存档恢复。

### B：原竞争者重逢

把长期人物记忆与临时契约分开保存，结清契约不删除仍有效的关系。保留最近一位合作/积怨人物，新建立或和解的关系持续十年，足以跨越失败后的两年冷却。下次远征优先选择实际出席且适格的旧识；合作75%/积怨70%的插曲概率只对这个人适用。缺席时按普通40%处理，随机新人不继承别人的关系；死亡的对象在入口清理，囚禁/失能时不作本场竞争者。

同人合作重逢提供确定的共同考据，增加5点活动进度且不发专长XP；积怨重逢可支付50金币调解，改善原人物关系并转为合作，不发进度或XP。均消费本场竞争者资格。本人若已是本场同行，不再同时扮演竞争者。延迟窗口以原NPC与本次遭遇编号复核。

验收：A合作后再遇A；改遇B；A缺席/死亡/囚禁/失能；A转为同行；旧场窗口点击新场；重复和解；不足50金币；无人物指针的旧合作旗标。新选择不增加必过随机关卡。

### C：家族底本与刊印

将七种真实有效知识编入当前家族分支 `house` 的持久收藏，同家后人可主动刊印。家族底本没有被动属性，不传个人XP、完成记录、圣物或契约。

| 操作 | 条件与成本 | 结果与限制 |
|---|---|---|
| 编目底本 | 持有对应有效笔记/图表；100金币，考据100XP时50金币 | 当前house新增该类收藏；同家同类只收录一次，不消耗当前副本 |
| 刊印副本 | 同家已有底本、本人没有该副本；40金币 | 对应知识5年有效，揭示对应远征；角色共用3年刊印冷却 |
| 使用副本 | 与原笔记/图表相同 | 五地笔记在同地出发消耗；图表在对应40金币首关消耗 |

编目保留当前副本，让“出发消耗”与“先投入建设收藏”形成顺序选择。冷却按人共用，不能在一次出发前将七类全部重印；副本已有时不能付费续期。收藏属于同一house，建立新分支不自动复制旧分支收藏。没有house的角色不开放入口。

菜单捕获打开时的house，点击时再次核对；换家后的旧窗口不收费、不跨家取知识。旧存档从空收藏开始，只有主动编目才新增底本。现有死亡档案仍按原流程运作。

验收：七类编目/刊印、研究满级折价、同家继承人使用、异家无权、打开后换家、知识过期、资金不足、重复点击、已有副本不刷新、共用冷却，以及印本进入真实远征被消费。
