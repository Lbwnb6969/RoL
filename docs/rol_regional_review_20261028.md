## 完成度结论

此前“四条完成”指四个短事件流程的阶段、奖励与尾声接通，表述超出了验证与内容范围。四条地方调查短线尚未达到原有五条活动远征的内容规格。亚历山大与耶路撒冷甚至仍是单事件试作。

| 项目 | 原有五条远征 | 新四条地方调查 |
|---|---|---|
| 入口 | 发现/传闻→活动界面 | 持有当地伯爵领后点决策 |
| 地点与时间 | 活动地点、旅行、等待、分期事件 | 持有头衔即操作，连续弹窗，没有实际旅行 |
| 挑战 | 独立分支、属性与整备概率、危机处理 | 四地共用25金币或10基础压力选择；无失败检定 |

| 美术 | 多阶段事件图、旅行图、活动图、header、图标 | 每地一张事件图，各阶段复用；同源裁制决策图 |

增加强制失败随机数、照抄旧活动不能单独解决这些内容差距。下一阶段仍应逐地设计自己的实际挑战、人物关系和长期结果，并按所选玩法决定接入活动或保留地方经营链。此处未将这些缺口冒充已完成，也未把本轮审计扩大成四条活动重写。

## 确认并修复的缺陷

1. **山道弓手缺图**：没有icon或illustration，游戏依照`_men_at_arms_types.info`默认查找不存在的同名图片。改为显式引用原版bowmen图标及横/竖插图。耶路撒冷原引用纳克索斯誓卫图，与实际兵种不符，改用原版heavy_infantry。它们是可用的原版素材，不宣称独立生图兵种立绘。
2. **已打开窗口绕过行动资格**：决策检查`is_available_adult`，事件按钮却只检查头衔、阶段和金币。打开窗口后被囚禁、开始旅行/活动或失去行动资格时仍可扣费领奖。增加共享可行动玩家触发器，在四条短线和两条试作的实际推进/支付选项复核。
3. **兵种资格外借**：当前游戏`access_through_subject`默认允许具备相关政体规则的领主借用属臣兵种，与“个人资格”不符。两个新兵种明确禁止通过属臣借用，原角色正常招募保持不变。
4. **奖励与成本反馈遗漏**：角色flag本身不能清楚说明解锁的兵种资格。两个招募解锁选项新增专用提示，四地决策说明补齐调查成本和后续100金币。
5. **组合验收缺口**：之前的组合检查检查新脚本编码、本地化与资源，但没有执行独立的地方短线状态模型。现将该模型加入`rol_static_audit.py`，输出区分五条活动远征与六条地方奖励路线。
