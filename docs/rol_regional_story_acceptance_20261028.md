# 四条地区故事验收

四条线均从直接持有对应伯爵领的玩家决策进入。流程是线索、调查、结局选择、只读尾声；可中途退出并由原决策接续。调查花25金币或承受10基础压力，实际压力由引擎及人物修正计算；调查后修复/研究另付100金币，公开成果免费获得100威望，两种最终结果互斥。

| 地点 | 伯爵领 | 起始事件 | 成果 |
|---|---|---|---|
| 杭州 | c_hangzhou | rol_asian_sites.0100 | 郡发展+35%、税收+20%，20年 |
| 山城 | c_yamashiro | rol_asian_sites.0200 | 当前人物可招募山道弓手，仍须付招募与维护费用并使用兵士编制 |
| 吴哥 | c_angkor | rol_asian_sites.0300 | 郡发展+35%、税收+20%，20年 |
| 巴格达 | c_baghdad | rol_asian_sites.0400 | 当前人物学习+5、学习生活方式经验+25%，10年 |

## 已执行检查

`python tools/ck3_mcp/rol_regional_story_contracts.py` 从真实事件AST执行两种调查×两种结果，覆盖决策按进度恢复、越过调查、重复调查窗口、资金不足、失去领地、重复结算和尾声无额外收益。模型不执行Clausewitz引擎、时间、人物压力倍率或实际兵种招募。

`python tools/ck3_mcp/rol_stdio_probe.py` 的组合检查涵盖脚本/本地化、BOM、资源引用、DDS与现有系统。图片沿用本批已生成的四地专用事件背景和四张决策插图。

## 游戏内核对

1. 由持有对应伯爵领的成年可行动玩家打开决策；也可控制台输入 `event` 加表中的起始事件，仍须持有对应领地。
2. 在线索后暂离、在调查后暂离，存读档后分别重开决策；应回到原阶段，调查不得再次扣25金币或加压力。
3. 最终金币不足时修复/研究选项不可选，免费公开仍可选；失地时只能暂离，恢复领地后原进度可继续。
4. 分别检查两种结果及尾声；完成后决策消失。重复旧结局窗口不应再次支付或领奖。旧版本已打开而缺调查阶段标记的窗口应关闭，由决策重新进入完成调查。
5. 山城在兵士界面检查招募资格与费用；杭州/吴哥在对应郡核对修正；巴格达在人像修正与学习生活方式经验提示中核对。确认事件背景遮罩与决策裁切。

调查进度与个人收益不转给继承人。郡修正按原版规则留在郡内；新的领主可展开自己的调查，重复同名郡修正的实际刷新行为须引擎验证。没有创建独立特殊建筑或新活动旅行。
