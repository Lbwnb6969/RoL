# RoL 系统加深与拓宽

## 当前目标与完成标准

按优先级逐轮形成有选择、有长期回报、相互影响的系统。玩家的远征经历应改变人物能力和关系，部分成果应支持下一次冒险，圣物使用应带来新的机会，继承人应能接续家族故事。现有五条活动、四件真品与 Naxos 单位继续作为基础。

四阶段已完成实现，本轮又完成技术/策划/数值全面静态审计与问题修复，交由维护者进游戏验证。完成证据与剩余引擎不确定性见 [完成审计](rol_completion_audit_20261007.md)；不把静态通过等同于游戏已验证。未来新增地区、宗教/DLC与AI玩法需另定范围。

## 实施优先级

| 阶段 | 玩法循环 | 当前状态 |
|---|---|---|
| 1 | 远征结算 → 复盘选择 → 三轨人物成长与限时研习；部分成功 → 地区笔记 → 下次同地远征优势 | 已接入五条活动，源码模型与静态验证通过；游戏界面/作用域待维护者验证 |
| 2 | 选择真实同行专家 → 贡献与互助 → 履约、声誉与长期关系；专长提供特殊路线 | 已接入五条活动，源码模型与静态验证通过；实际宾客作用域与定时结算待维护者验证 |
| 3 | 圣物用途选择 → 条件性收益与回报事件 → 调整用途；避免无限叠加 | 已接入四件真品与Naxos传统，共十种用途；静态通过，装备/UI/物品转手回调待维护者验证 |
| 4 | 星球研究 → 星盘线索 → Naxos 航路等可选跨链路线；成果/约定的代际接续 | 两条可选路线、七类档案与原人物约定接续已落地，源码模型通过；死亡/继承回调与排队作用域待维护者验证 |

优先复用已存在的 rival、legacy、fragment 事件和共享模板；必要时改进原有事件，让新系统有自然入口。新增地区与宗教/DLC 桥接放在以上循环之后，避免在玩法深化前增加大量同构活动。

## 第一阶段：已实现的循环

- 五条活动的真实 `on_start` 建立一次结算资格。完整成功给30点复盘经验；Tier2/3 部分成功给20点；完成至少一个阶段后的失败给10点；未有阶段进展的失败、无活动上下文的直接 finalize 不产生经验。
- 两天后出现复盘事件，玩家将经验投入考据、探险或交涉。20/60/100经验分档，提高学习、旅行安全/武勇或外交；经验为个人所有，继承圣物不会自动继承专长。
- 所选方向给三年的研习：学习生活方式经验+5%、旅行速度+5%或普遍好感+3。研习互相替换；勤勉/勇敢/合群分别匹配三个方向，额外失去5点压力。
- 部分成功另给对应地区十年笔记。下次同地活动开始时消耗，在该活动的共享二元检定中增加5个百分点，仍受95%封顶；其他地区不消耗。同地笔记刷新而不叠加。
- 原有五年圣物证据学习修正、两年冷却和完整圣物门槛保留。新的地区笔记承担重试帮助，两个修正用途不同。
- 若自动复盘未能显示，待处理经验保留；玩家可通过“复盘远征经历”决策重新打开。多次打开事件不重复兑现经验或压力收益。
- 复盘复用现有无人研究场景和原版 traveler 特质图标；没有生成或替换可用图片。

## 第二阶段：同行、履约与专长路线

- 抵达后，从实际出席的成年、存活、未被囚禁且未失能宾客中，选出学习/武勇/外交至少12的候选；可以选择学者、护卫、交涉者，或不订约继续原路线。原版 `is_available_adult` 排除正在参加活动者，本模块不用它筛选同行。
- 学者仍活着且出席时，共享二元检定增加3个百分点；与地区笔记叠加，仍封顶95%，显示和实际共用算式。护卫提供一次75金币的确定高档开局；交涉者提供一次和平化解竞争者争执的选项，改善进度并减10压力。不保证竞争者出现。
- 任一探寻者轨道达到60经验，解锁100金币的确定高档开局，不依赖同行。护卫与专长路线共用一次限额，只替代第一道检定；沿原有成功反馈与阶段推进，仍须完成后续阶段和Tier4门槛。
- 原人物指针保存在角色变量中，归来四天后按原约定结算：学者50威望、护卫50金币付给同一人物、交涉者75威望。充分履约获得双方五年+25好感、三年普遍好感+3的守信声誉，并保存该人物为老搭档；下次仍到场且合格时优先入选。这是候选优先与好感关系，不自动建立原版好友关系。
- 至少推进过一个阶段时，充分履约另给对应轨道10经验；协商补偿25金币给原人物、获得尊重和5经验，但不新增老搭档或守信声誉。未推进便退出，不奖励经验。拒绝履约带来-20好感、三年普遍好感-3，移除对该人物的既有老搭档记录；诚实/公正者加15压力。
- 暂缓结算不奖励、不自动催促，可用决策重开；旧约未结清时，新远征照常进行但不能重选签约者。死亡/失效参与者关闭记录而不付款、不奖励、不换人。离队立即停止现场帮助，已经订下的报酬仍待处理；活动异常失效后的下次出发会恢复原约定，但不凭空认定阶段经验。
- 现场帮助、费用、队伍进度、定时结算与经验均有一次守卫。守信/失信声誉互相替换，同类刷新不叠加。复用已有契约/传承图片，无新生图。

## 第三阶段：圣物投入使用

通过“安排圣物用途”决策，选择实际持有的真品，或已经解锁的Naxos守卫传统。每次立项花50金币，一年内不能另立项目；未结算的项目也会阻止新立项。每个对象两种用途，切换只替换其用途修正，原有真品/碎片属性保留。没有创建圣物、替换可用图片或新增随机关卡。

| 对象 | 用途一 | 用途二 |
|---|---|---|
| Mars剑 | 骑士演练：装备时骑士战斗力+5%，成果投探险 | 公开誓约：装备时普遍好感+3，成果投交涉 |
| 星界球 | 持续观测：装备时学习生活方式经验+5%，成果投考据 | 来访展陈：装备时每月威望增益+5%，成果投交涉 |
| 星盘 | 路线校准：装备时旅行速度+5%、安全+5，成果投探险 | 研习教学：装备时学习+1、学习生活方式经验+3%，成果投考据 |
| 金面 | 威慑象征：装备时恐怖增益+5%，成果投交涉 | 保存研究：装备时压力损失增益+5%，成果投考据 |
| Naxos传统 | 配合训练：三年骑士战斗力+5%，成果投探险 | 老兵授课：三年军事生活方式经验+5%，成果投探险；不直接创建兵团 |

- 四件真品的用途加成直接挂在选定artifact上，只在装备时提供原版装备效果。未装备仍可完成计划研究。用途持续到切换/主动停止/换主；转手回调在玩家/AI分支之前清除旧部署，新主人自行决定用途。没有把这些加成复制到原主人角色。
- 180天等待结束后，第181天排队打开一次成果事件，避开标记到期和事件触发同tick的先后问题。选“记录本领”给表中轨道10经验，匹配性格额外减5压力；选“公开成果”给100威望且不给专长经验。两者只结算一次，当前用途保留。
- 原始物品指针、模式和单调递增的项目编号共同校验。换主、物品失效、换模式或丢失Naxos资格的项目不奖励、不退款、不抽另一物品代替。旧排队事件不能兑现后来项目。
- 暂缓后可用“整理圣物用途成果”重开；成熟之前恢复入口和兑现效果都被180天等待标记阻止。延期到Naxos三年训练过期时，项目按失效收束。
- “停止圣物部署”可随时移除所选用途，若对应项目仍待处理则一并取消；无退款、无奖励、保留一年冷却。停止另一件已部署圣物，不应取消当前对象的项目。
- `rol_relic_use_contracts.py` 读取十种实际选项验证费用、互斥、原物品/原属性保留、等待门槛、同编号恢复、过时事件、换主/换模式、资金不足与主动停止。模型不模拟游戏时间、随机挑选或装备加成，只验证过滤与源码生命周期。

## 第四阶段：研究线索与代际接续

- 星界球“持续观测”半年成果选择记录本领时，另产出十年观测图并揭示Sevilla入口；星盘“路线校准”记录本领另产出十年爱琴海航路并揭示Naxos入口。公开成果只给原100威望，不发图表。相同图表刷新，不叠加；资料没有被动属性。
- 对应真实远征的第一道难关可花40金币，消耗对应图表，获得确定高档推进并进入原 `.1010` 反馈。与护卫/专长路线共用一次限额；没有活动、地区不符、资金不足或已用稳妥开局，不收费/不耗图。原有独立路线与Tier4门槛保留。
- 玩家死亡回调将五类仍有效地区笔记、两类图表及未读档案打包给存活的 `player_heir`，不依赖回调当刻继承人是否已成为玩家。多份档案合并；七天后可花50威望整理，新增副本五年有效，已有同类资料不刷新、不缩短。可延期或封存；个人专长XP、待复盘XP、进行中的圣物项目、原有完成flag与物品归属不由档案复制。
- 原物品继承依靠CK3原版；本模块不创建或重复发物品。Naxos原有继承入口保留，修正了过早检查继承人AI状态和100金币费用门槛；三年训练修正不直接继承。
- 未履行的个人同行约定（在途或已待结算）将原人物和角色职责快照保存在原签约者上，并以来源人物队列递交。已收到但未处理的来源队列也会传到下一位继承人，不丢失、覆盖或重复同一来源；没有全局扫描或生成新NPC。
- 八天后/恢复决策逐份打开约定：继承人可主动承担、保留或不承担。已有个人约定时不能承担新记录来覆盖；承担后接入已有履约/协商/暂缓/拒约流程，继承的earned XP固定0，守信收益属于主动履约的继承人。尚未承担时不予继承不强加失信声誉；死亡/失效的原人物只关闭该来源，不替换收款人。其他档案与约定保留。
- `rol_archive_contracts.py` 检查真实生产/消费、错误地区与重放、多来源/再次死亡传递、原快照身份、已有同行保护、过早AI条件、档案年限与不继承XP。该有限模型不模拟死亡顺序、原版物品继承、排队保存或新玩家选择。

## 设计准则与后续维护

### 人物与关系

同行者应是同一个可追踪人物，其能力、性格和经历影响选项。贡献之后产生值得兑现的约定，例如共同署名、支付报酬或认可其地位。合作给予可靠帮助，违约有可预见的关系代价。死亡、离队或身份变化后有适当收束，不创建无期限重复 NPC。

原版性格提供不同代价/压力和不同解决方法，避免某个性格必然最佳。高专长可以解锁鉴定、带队或谈判选项；原有高属性角色不依赖新特质也应保有合理胜算。

### 圣物、BUFF与联动

每种用途要有不同机会与限制。暂定 Mars 的佩用/誓约、星球的研究/展示、星盘的导航/知识传播、面具的威慑/修复，以及 Naxos 的作战/训练。选择某用途不应简单得到更多无条件永久属性。

所有收益明确受益对象、期限、刷新/叠加、切换和结束条件。特定 artifact 升级前再次验证归属；延迟人物事件验证参与者仍有效。跨链主要提供线索、选项、费用节省或一次补救，各链仍可独立完成。

继承优先转移物品、笔记和约定，不转移前任个人经验。继承人可以接受或重新商谈职责。保留旧四链圆环条件与独立五链增强语义，兼容缺少新状态的旧存档。

## 概率与反馈

约70%是早期设计目标；2026-10-07按源码纠正主阶段数：Rome四关，Naxos三关，Munich/Sevilla/Carthage各两关。Rome稳定开局后标准有利路线参考72.9%，Naxos稳定开局及其他两关链参考81%，两关链付费稳定首关后参考90%。不为统一文档暗改既有90%分支。乘积不含旅行、竞争者或宾客进度损失，具体路线与费用见 [数值模型](rol_success_model.md)。

实际与显示概率共用script value，单次95%封顶。新叙事优先增加选择和回报，不增加必过随机关卡。极致筹备在高属性上与高档同概率、但更贵；免费学习与付费稳妥路线各有适用人物，不宣称所有选项等值。部分成功只拿部分成果，不再拿完整凯旋筹备奖励。终局装备与碎片的累计强度保留，实际战斗/经济节奏等待手测。

## 本轮审计收尾与后续范围

- 已退役五个全局原版GUI和custom loc覆盖，品质/类型交回原版；传奇徽记只挂自有阶位修正。新增兼容门槛拒绝原版同路径替换、全局本地化key与未解析自有引用；可用图片全部保留。
- 五链按原主办者/活动类型/地区/关闭状态复核，101个阶段按钮再验点击资格；完整/部分/失败只结算一次，主动安排一天阶段收尾。失效统一失败收口，死亡保留原约定供档案继承、不发个人XP。
- 四/五链圆环永久一次领奖，识别已有旧奖励；最后一件换主/Naxos承接检查联动，Naxos接受/拒绝均按原前任一次应答。竞争者保存原NPC、一次消费与恢复入口；三种传承取向互斥。
- 完整系统阶段到此结束；先按控制台指南第16节兼容验收，再按6、12–15节检查真实活动、装备、定时、存读档和继承。只有具体手测问题或新需求才继续开发，不新增同构活动、地区、DLC或AI范围。

## 验证边界

`rol_static_audit.py` 已纳入 `rol_growth_contracts.py` 与 `rol_companion_contracts.py`，读取真实模块脚本，验证五条入口和结算参数。有限源码模型检查笔记生产/消耗、资格关闭、研习替换、候选资格/老搭档优先、无人队伍回退、同人支付、离队/死亡/资金不足、异常活动恢复、重复兑现以及实际/显示概率算式。该模型只解释本模块所用的一小部分语法；未知指令报错。原版活动进度效果只检查调用次数及接线，不模拟引擎进度数值。

模型不是 CK3 引擎，不证明运行时 scope、Trait UI、延迟事件显示或真实时间到期。后续仍按用户要求不启动游戏；测试入口和预期写入 `docs/rol_console_test_guide.md`，由维护者在独立测试存档验证。每轮完成相关最低充分静态检查，留好 Git 备份并记录未验证项。
